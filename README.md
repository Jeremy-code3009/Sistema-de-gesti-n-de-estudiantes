## Descripción breve
Aplicación de escritorio desarrollada en C# utilizando Windows Forms bajo el paradigma de programación orientada a objetos. Su propósito es permitir la administración completa (CRUD) de estudiantes de forma centralizada mediante un menú modular.

---

## Datos de entrada
Información ingresada a través de los controles de los formularios:
* ID / Matrícula del estudiante
* Nombre completo
* Edad
* Sexo / Género
* Carrera universitaria

---

## Datos que procesa
* Validaciones de campos vacíos y tipos de datos numéricos.
* Manejo de excepciones y control de nulos en búsquedas.
* Operaciones sobre listas dinámicas: registro, filtrado/búsqueda, actualización de propiedades y eliminación de registros.

---

## Datos de salida
* Listado de registros mostrados en tiempo real a través de controles `DataGridView`.
* Mensajes de confirmación, advertencia y error mediante cuadros de diálogo (`MessageBox`).
